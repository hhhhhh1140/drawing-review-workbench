PURE BROWSER PIPELINE

六阶段 CAD 矢量图元拓扑 + 靶向局部 OCR 解析架构

无需后端服务 · 解决 CAD 矢量化丢符号、公差拆碎与分块截断痛点
01双路流提取与图层去重

同步提取 getTextContent() 与 5万+ constructPath 矢量图元，消除 CAD 多层重复文字流，执行 NFKC 字根与字距紧凑归一化。

02图框分区与闭合 △ 几何滤噪

几何识别双斜边+水平底边闭合等腰三角 △1~9 与外圈图框坐标 1~16 / A~H 精准滤除，完整保留矩形框理论尺寸与基准符。

03并查集（Union-Find）网格重建

由横纵线段经并查集还原标题栏真实单元格与变更表行；遮罩已知取值后靶向识别转曲表头，自动配对同格与上下跨格键值。

047 类形位公差框几何解码

检测等高毗邻公差框链，从首格同心圆/平行四边形/十字线直接解码 ⊥ ▱ ∥ ≡ ○ ◎ ⌖，旋转摆正竖排框并分离 ⌀ 与 Ⓜ。

05矢量符号还原与上下偏差合并

在局部阅读坐标系中找回被 CAD 画成短线段的负号 −、前置直径符 ⌀ 与后置转曲对称公差 ±，自动拼合上下极限偏差。

06转曲段落连通聚类 & 气泡号绑定

对未覆盖笔画做网格连通聚类，整块送入 OCR 彻底杜绝分块拦腰截断；按最短边缘距离将全图 【1】~【N】 气泡号精准配对。
